## DO NOT DOWNLOAD IT AS A ZIP  
It's useless anyway, as the folder will be empty due to the way the repository is structured  
Use Git CLI instead in CMD  
Then, run `cd ` followed by the path to wherever you want to clone the repository  
Here's the command you'll need to use : `git clone --recurse-submodules https://github.com/Zelos64/Xenoforge.git`  
If you want to update the local repository, run : `git pull --recurse-submodules`
